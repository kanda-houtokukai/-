# 08 読み仮名版台本（ElevenLabs 入力用）

作成: 2026-09-05　　用途: 音声合成に**そのまま**渡すテキスト
正本は `04_ナレーション台本.md`。**04 は変更しない**（人が読む版と機械に渡す版を分ける）。
内容・語順・言い回しは 04 と同一。読み違えの起きる語を **かな書きに置換**しただけ。

## 使い方

- 章ごとに `---` で区切ってある。**1章ずつ別ファイルとして API に渡す**（章ごとに音声を作り、章ごとに尺を確定させるため）。
- 【画面】の行、太字の `**`、注記の（ ）は**すべて削除済み**。読み上げる文だけが残っている。
- 発音辞書には頼らない。辞書に登録しても本文をそのまま生成すると読みが変わらない事例が報告されているため、**本文の側をかなにしてある**。
- 句点の直後の改行は、そのままポーズになる。改行を勝手に詰めないこと。
- 生成は `/with-timestamps` エンドポイントを使い、文字単位の開始・終了秒を JSON で保存する（映像側の同期に使う）。

## 英語のフレーズについて

日本語音声が英文を読むと崩れるため、**カタカナに置換**してある（画面には英語のつづりを出すので、意味は伝わる）。該当は3か所。
- ヒー・プロフィッツ・モスト・フー・サーブズ・ベスト（He profits most who serves best）
- ユナイト・フォー・グッド（Unite for Good）
- クリエイト・ラスティング・インパクト（Create Lasting Impact）

試聴して不自然なら、英語のまま渡す版に戻して聴き比べる。
