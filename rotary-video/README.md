## 事実の確認状態の読み方（鉄則5: データの正確性）

- **[確認済]** … 公式・一次情報（rotary.org、RI日本事務局 rotary.or.jp、米山記念奨学会、ロータリーの友、GPEI/WHO など）の検索結果で確認できたもの。
- **[要検証]** … 二次情報（クラブ・地区サイト、報道、百科事典など）でしか確認できていないもの。**動画に載せる前に原本で確認する。**
- **[記憶]** … 調査結果に無く、作成者（AI）の知識で補ったもの。**必ず原本で確認する。**

> ⚠️ 制作環境の制約: 今回の調査はWeb検索の結果（要約スニペット）のみで行い、公式サイトの本文を直接開くことができませんでした（ネットワーク制限）。そのため「確認済」でも**本文での再確認を推奨**します。特に会員数・寄付額・症例数は年度末の締めで数字が動きます。

## 教訓
- ★ 公式サイトが読めない環境では、検索スニペットの数字は「年度」「時点」がずれやすい。時点（as of）を必ず併記する。
- ★ 同じ事実でも出典によって数字が違うものが多い（1940年脱退時48/45クラブ、女性比率8.3%/12.94%、Charity Navigator 15/17年連続、2004年大阪45,381/45,560人）。**両方の値を残し、動画では一方を断定しない**か、公式の値だけを使う。
- ★ 図表は「未検証の点を白抜き・斜線」で描く設計にした。確認が済んだら `scripts/data.json` の status を verified にして再生成すれば塗りつぶしになる。数字の確認と見せ方を分離できる。
- ★ Web検索は1セッション200回の上限がある。並列の調査エージェント4本で使い切った。次回は1本あたりの検索数を指示に明記する。
- ★ 図の注記・カードの文言が make_charts.py に直書きされていたため、data.json だけ直しても図に古い数字が残った。文言もデータ側に置く。
