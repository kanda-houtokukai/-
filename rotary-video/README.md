# ロータリー変遷動画（卓話用）— 素材一式の台帳

最終更新: 2026-09-02　　正本: このフォルダ（`rotary-video/`）

## 現在地サマリ

- **案件**: 所属ロータリークラブの卓話で上映する「ロータリーの変遷」動画の、調査と素材づくり。
- **狙い**: 在籍数十年の会員にも「へえ」と言わせる。歴史の年表だけでなく**数値**と**深掘りネタ**、そして**直近（2023〜2026年）の世界・日本の方針**を入れる。虚偽は絶対に入れない。
- **今回の到達点**: 調査ノート（出典付き）・数値データ集・動画構成案・ナレーション台本・図表画像・クイズ案を作成。
- **次の一手**: ①数値データ集の「⚠️要検証」項目を原本URLで確認 → ②台本の尺と語りを実際に読んで調整 → ③図表を動画編集ソフトへ取り込み。

## 事実の確認状態の読み方（鉄則5: データの正確性）

- **[確認済]** … 公式・一次情報（rotary.org、RI日本事務局 rotary.or.jp、米山記念奨学会、ロータリーの友、GPEI/WHO など）の検索結果で確認できたもの。
- **[要検証]** … 二次情報（クラブ・地区サイト、報道、百科事典など）でしか確認できていないもの。**動画に載せる前に原本で確認する。**
- **[記憶]** … 調査結果に無く、作成者（AI）の知識で補ったもの。**必ず原本で確認する。**

> ⚠️ 制作環境の制約: 今回の調査はWeb検索の結果（要約スニペット）のみで行い、公式サイトの本文を直接開くことができませんでした（ネットワーク制限）。そのため「確認済」でも**本文での再確認を推奨**します。特に会員数・寄付額・症例数は年度末の締めで数字が動きます。

## 決定事項

- [DECISION] 素材はこのリポジトリの `rotary-video/` 配下にまとめる（既存の送迎ルート案件とは独立）。
- [DECISION] 動画の骨格は「**数字で読むロータリー**」。各章を1つの数字で始め、既知の話も「数字の意外性」で新鮮に見せる。
- [DECISION] 数字には必ず出典と確認状態を付け、要検証のまま動画に載せない。

## 教訓
- ★ 公式サイトが読めない環境では、検索スニペットの数字は「年度」「時点」がずれやすい。時点（as of）を必ず併記する。
