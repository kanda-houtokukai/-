## 1. 制作方式（確定）

| 項目 | 決定 | 背景 |
|---|---|---|
| 映像 | Remotion（React でコード生成） | PowerPoint 風・テンプレート感を避け、広報PR動画の水準を狙うため |
| ナレーション | ElevenLabs（AI音声・日本語） | 全自動化。本人収録は行わない |
| BGM | DOVA-SYNDROME（著作権フリー） | 商用利用可・クレジット条件を確認して使用 |
| 写真 | **使わない**（2026-09-05 確定） | 自クラブの掲示物の撮影も検討したが、手元に素材がないため不採用 |
| 実在人物の画像 | **使わない**（AI生成も含む） | 故人・実在人物の肖像を作らない |
| 画面比・尺 | 16:9 / 1920×1080 / 30fps / 約15分 | 卓話30分枠のうち上映15分 |

---

## 2. この案件の設計原則（6つ）

1. **1画面1数字。** 数字は画面高の40〜60%。本文は1080p換算で54px以上（会場最高齢70代 ÷2 = 35pt 相当）。細字・薄いグレーは使わない。
2. **情報は画面の上80%に置く。** 下20%は出典表示のみ。前席の人の頭で隠れても本編が成立する。
3. **金は「数字」と「印」専用。本文は白か紺。** 金地に本文を長く置かない（可読性と品位の両方を損なう）。
4. **動きは意味に従う。** 数字は登場時に一度だけ動き、以後は静止。意味のない動きを足さない。
5. **章ごとに大胆な演出は1つだけ。** 他は静かに保つ。
6. **絵の巧拙に依存しない。** 人物は「名前・職業・年」の文字組で見せる。図形で正確に描けるもの（歯車・車輪・グラフ）だけを描く。

## 3. 質感（案C「反転」で確定）

- **本文画面**: 地 = ロイヤルブルー `#17458F`、文字 = 白 `#FFFFFF`、強調 = ゴールド `#F7A81B`
- **数字カード**: 地 = ゴールド `#F7A81B`、数字と説明 = 紺 `#17458F`
- **書体**: 本文・見出し = BIZ UDPGothic（Google Fonts）／数字 = Oswald（Google Fonts）
- **反転の意味**: 章の切れ目だけ金地になる。10章の反復が単調にならないためのリズム。金地は1章あたり4〜5秒以内に必ず戻す。
- 使わないもの: グラデーション背景、影、角丸カード、パーティクル、光沢。

### 文字サイズ（1080p基準・固定値）

| 用途 | サイズ | 太さ |
|---|---|---|
| カードの数字 | 560〜760px（桁数で調整・画面幅の85%を超えない） | Oswald 700 |
| カードの説明 | 56px（時点の注記は38px） | 700 / 400 |
| 章見出し | 100〜112px | 700 |
| 本文 | 54px（行間1.7） | 400（強調のみ700・金） |
| 出典 | 26px（不透明度75%） | 400 |

## 4. 動きの型（「1 置く」を基本に確定）

- **数字の登場**: 一瞬で現れて静止（動かさない）。0.3秒でフェード、以後3秒静止してからナレーション開始。
- **図の現れかた**: 棒・線は下から伸びる（1.0〜1.2秒、easing = `Easing.bezier(0.16, 1, 0.3, 1)`）。値のラベルは伸び終わってから点く。
- **場面転換（全章共通）**: 金の数字カードが上へ抜けて、下から本文画面が現れる（0.9秒）。
- **例外① カウントアップは全体で3か所だけ**: 第0章（4 → 1,200,000）、第6章（350,000件 → 22件のカウントダウン）、第10章（1,200,000 → 1,250,000）。ここは数字が動くこと自体が語りなので効く。他章で使うと動きが意味を失う。
- **例外② 黒コマは全体で1回だけ**: 第5章の「1940年 脱退」の直前に0.3秒の黒を挟む。暗い場面の重さを出す唯一の演出。
- 禁止: スライドイン連打、ワイプ、回転、パーティクル、文字の1文字ずつ登場（PowerPoint感の主因）。

---

## 5. 図表の扱い（確定）

- `charts/*.png` は**動画では使わない**。同じ数値を Remotion で描き直す。理由は、①アニメーションできる ②解像度が自由 ③数値を直せば図も直る。
- 元データは `scripts/data.json` を正本として流用する（数値の二重管理をしない）。
- 描く図は3点のみ: **第6章のポリオ症例数（対数の折れ線）／第8章の分担金（階段）／第9章の日本の会員数（折れ線）と女性比率（2本の棒）**。
- 出典表示は図のある画面に必ず入れる（画面右下・26px）。

## 6. 章別の絵コンテ

各章とも【カード】（金地・3〜5秒）→【本文】（紺地）の順。転換は共通型。

### 0. オープニング（0:40）
- 【カード】黒 → 紺へ明転。中央に `4` が現れ、**1,200,000 までカウントアップ**（1.6秒）。到達後に「1905年 → 2026年」の小さな注記。
- 【本文】タイトル「数字で読むロータリー120年」を紺地・中央。副題「120万人の始まりは、4人でした」。
- 演出の位置づけ: この章のカウントアップが全体の「掴み」。以後は静かに。

### 1. 4人と711号室（1:00）
- 【カード】`4`（説明: 1905年2月23日、シカゴ・ユニティビル711号室）
- 【本文A】4人の名前を職業つきで縦に4行。1行ずつ0.4秒差で置く（顔は出さない）。
- 【本文B】`711` を大きく置き、その周りにビルの窓を模した矩形グリッドを薄く。凝らない。
- 【本文C】「1907年 最初の奉仕は公衆トイレ」を1行で。

### 2. 24と6、そしてキー溝（1:00）
- 【カード】`24 / 6`（説明: 歯の数とスポークの本数）
- 【本文A】**歯車のSVGを実寸で描く**（唯一の作図）。1905年の荷馬車の車輪（スポーク13本）→ 現在の24歯6本へ、0.8秒で形が入れ替わる。
- 【本文B】キー溝の位置に金の丸を置いて拡大（1.0倍→2.2倍、静止）。添え文「働き者であって、怠け者ではない」。
- 俗説の否定（歯数に象徴的意味はない）は本文テキストで明示する。

### 3. 言葉は変わる（1:30）
- 【カード】`1932`（説明: 四つのテストの誕生年）
- 【本文A】標語の変遷を横一列の3点年表で。`He`(〜2004) → `They`(2004) → `One`(2010) と、語だけが置き換わる（位置は動かさない）。
- 【本文B】四つのテストを4行。1行ずつ置く。行頭に金の細い縦線。
- 【本文C】「1954年 公募 70数件 / 当選 本田親男（東京RC）」を文字組で。

### 4. 855番目のクラブ（1:30）
- 【カード】`855`（説明: 世界で855番目のクラブとして承認 1921年4月1日）
- 【本文A】1918年ダラス。米山梅吉・福島喜三次の名前を2枚の紺の名札状の枠で（写真なし・肩書きのみ）。
- 【本文B】日付の縦積み: 1920年9月1日 準備会 / 10月20日 創立総会 / 1921年4月1日 承認。上から順に置く。
- 【本文C】「サービス第一、自己第二」を大きく1行。

### 5. 48から7へ（1:30）
- 【カード】`48 → 7`（説明: 1940年 脱退 / 1949年 復帰・クラブ数）
- **【黒コマ】0.3秒**（全体で唯一）
- 【本文A】「1940年 昭和15年」。48個の小さな金の四角を並べ、7個を残して**消える**（0.8秒・伸びるのではなく消える）。
- 【本文B】「水曜会」「金曜会」の2語を左右に。看板を下ろす含意は文字のみで。
- 【本文C】1949年3月の復帰3条件を3行。旧番号855で再登録を金で強調。

### 6. 26ドル50セントから30億人へ（2:00）
- 【カード】`$26.50`（説明: 1917年 最初の寄付・カンザスシティRC）
