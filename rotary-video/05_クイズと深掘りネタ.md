## A. 会場クイズ（10問・3択）

答えの後に「一言解説」を付けてある。上映を止めて投げる場合は1問30秒。

1. **最初の例会が開かれた部屋番号は？**　①305　②711　③1905
　→ **②711**。ユニティ・ビル711号室、ローアの事務所。✅
2. **歯車の歯の数「24」の意味は？**　①1日24時間　②創立時の会員数　③意味はない
　→ **③意味はない**。「実際に動く歯車らしく」というだけ。✅（RGHF）
3. **ロータリー財団への最初の寄付額は？**　①$26.50　②$100　③$1,000
　→ **①$26.50**。1917年、カンザスシティRC。✅
4. **東京ロータリークラブの世界登録番号は？**　①第1号　②第100号　③第855号
　→ **③855**。1921年4月1日承認。1949年の復帰時も同じ番号で再登録。✅
5. **戦時中、東京の元ロータリアンが集まった会の名前は？**　①月曜会　②水曜会　③土曜会
　→ **②水曜会**（大阪は金曜会）。1949年の復帰条件の1つが「水曜会の解散」。✅
6. **「四つのテスト」を作った人の職業は？**　①牧師　②弁護士　③倒産寸前の会社の経営者
　→ **③**。ハーバート・テイラー、クラブ・アルミナム社（負債40万ドル）。✅
7. **2004年大阪大会の有料参加者数は？**　①約2万人　②約3万人　③約4万5千人
　→ **③45,381人**。いまも史上最多。✅
8. **1988年、世界のポリオ症例は年間およそ何件？**　①3万5千　②35万　③350万
　→ **②35万件・125か国**。✅
9. **2025-26年度から「会長テーマ」はどうなった？**　①英語のみになった　②「会長メッセージ」に変わった　③2年ごとになった
　→ **②**。2023年10月理事会決定。⚠️（地区サイト情報、my.rotary.orgで確認）
10. **2026-27年度RI会長の出身国は？**　①ブラジル　②韓国　③ナイジェリア
　→ **③ナイジェリア**（ババロラ氏）。当初の会長エレクトは韓国のユン氏だったが病気療養で辞任。✅

## B. ベテラン向け「深掘り」ネタ（卓話の合間・懇親の話題に）

### 世界
- **ダブリンかロンドンか**: 北米外で最初に「集まった」のはダブリン（1911年2月22日）、最初に「認証された」のはロンドン（1912年8月1日）。どちらを「最初」と呼ぶかで答えが変わる。✅
- **標語の性別**: He profits most… → They（2004）→ One（2010）。2回書き換えられている。✅
- **「目的」の条数は7回変わった**: 3→5→6→4→6→4→1（1906→1951）。✅
- **最初のラペルピン**は1909年10月14日、ニューヨークRC。8本スポーク、歯なし、キー溝なし。✅
- **ロータリー・アン**の由来: 1914年、ヒューストン大会へ向かう列車で唯一の女性だったアン・ブルニエ夫人。夫ブルニエは1952年にRI会長。⚠️
- **国連憲章と49人**: 1945年サンフランシスコ会議、800人の代表・顧問のうち49人がロータリアン。1942年ロンドンの21か国ロータリー会議がユネスコの先駆け。✅
- **1分類1会員**の時代: クラブに歯科医がいれば、次の歯科医は欠員が出るまで入会できなかった。⚠️
- **RYLAの発端**は1959年、クイーンズランド州100年祭にアレクサンドラ王女が来ることになり、同世代向けの催し「グンドゥー」を開いたこと。⚠️
- **本部の建物**: 1954年開所のリッジ通り1600番地は「新築」、1987年のワン・ロータリー・センターはバクスター社からの「購入」。18階建て。✅
- **トーマス・マン**はミュンヘンRCの創立会員だったが1933年に除名。**アデナウアー**はケルンRC（1928-33）。ドイツのロータリーは1937年に自主解散。⚠️
- **ソ連初のクラブ**はモスクワ、1990年6月5日認証。⚠️
- **最南**はアルゼンチンの南極マランビオ基地、**最高所**は標高4,880mのエル・アギラール（アルゼンチン）。⚠️
- **財団史上最大の個人寄付**はインドの実業家による5,000万ドル。⚠️
- **恒久基金「2025 by 2025」**は期限の6日前に達成。⚠️
- **Rotary Showcase は2024年8月に廃止**、Service Project Center へ。✅

### 日本
- **東京RC創立総会は帝国ホテルではなく「銀行倶楽部」**（三井銀行関連）。⚠️（東京RC史）
- **米山梅吉の月桂樹**（1935年ポール・ハリス植樹）の挿し木二世が北の丸公園に現存。✅（ロータリーの友）
- **1939年の地区**: 第70（東日本・樺太20クラブ）、第71（西日本・台湾19）、第72（朝鮮・満州7）。✅
- **復帰の条件は3つ**、東京RCへの認証状伝達式は1949年4月27日、日本工業倶楽部。✅
- **米山奨学第1号**は1954年タイからのソムチャード氏（東大で養蚕学、帰国後タイシルク増産に貢献）。1967年の財団法人化時は年59人。✅
- **『ロータリーの友』の創刊は岐阜・長良川畔の旅館での会議（1952年8月16日）で決まった**。定価50円、3,300部。✅
- **四つのテストの標題**を決めたのは手島知健（RI理事）、訳の当選者は東京クラブの本田氏。⚠️氏名の表記に2説
- **1961年東京大会**は「国際理解による世界平和」がテーマ。国内16,000人・海外7,000人（外務省資料）。✅
- **1978年東京大会**で3-H補助金を発表したのはクレム・レヌーフ会長。翌年のフィリピンのポリオ事業がその第1号。✅
- **ロータリー文庫**は1970年11月1日、有楽町ビルの東ヶ崎潔氏の事務所の一角から始まった。✅
- **ロータリー日本財団**の公益認定は2010年12月24日（クリスマスイブ）。✅
- **ニコニコボックス**は1936年、大阪RC発祥説と東京RC（関幸重氏・関東大震災の孤児300名招待）説。✅
- **日本の女性会員比率は記事によって8.3%と12.94%**。定義（正会員のみか等）が違う可能性。動画では確認した方だけを使う。⚠️
- **外務省の資料**（2026年）に日本のロータリーの会員数が載っている（2,174クラブ・83,297人）。政府文書に載るほどの存在。✅

### いま（2025〜26）
- **2年連続で会長エレクトが辞任**し、理事会が会長を選び直した。✅
- **2027年大会はホノルルからバルセロナに変更**。ホノルルは2032年に。✅
- **規定審議会の費用として7月に会員1人1ドル**が追加請求される。✅
- **ゾーン8（豪NZ）は2028-29年度のガバナー選挙を停止**して新地区案を検討中。✅
- **日本政府もパキスタンのポリオ根絶に毎年無償資金協力**（2024年12月$310万、2025年11月$350万）。✅／⚠️

## C. 言ってはいけない・裏付けのない話（俗説チェック）

| よく聞く話 | 判定 | 根拠 |
|---|---|---|
| 「歯車の24歯は1日24時間、6本スポークは六大陸を表す」 | ✕ | 公式記録では象徴的意味なし（RGHF）。 |
| 「湯川秀樹はロータリアンだった／京都RCで卓話した」 | 裏付けなし | 複数検索でも記録なし。 |
| 「渋沢栄一は東京RCの名誉会員」 | 裏付けなし | 記録見つからず。 |
| 「皇族がロータリアンだった」 | 裏付けなし | 1961年大会での天皇陛下の開会の辞は事実だが会員ではない。 |
| 「ロータリーの旗が月に運ばれた」 | 裏付けなし | NASA・スミソニアン資料に記載なし。南極点への旗（1922年バード提督）は⚠️。 |
| 「ロータリーにちなんだ小惑星がある」 | 裏付けなし | 類似名の小惑星のみ。 |
| 「ウォルト・ディズニーはロータリアン」 | △ | パームスプリングスRCの**名誉会員**（rotary.org）。正会員ではない。 |
| 「松下幸之助は大阪RC会員」 | ⚠️ | 個人ブログ等のみ。大阪RCの会員名簿・記念誌で確認してから使う。 |
| 「日本の会員数はピーク13万人」 | ⚠️ | 検索では裏付けなし。RI日本事務局の年次統計で確認。 |
| 「1940年、45クラブで脱退」 | ✕（数字） | ロータリーの友の資料では**48クラブ**。 |
| 「1978年東京大会のRI会長はジャック・デービス」 | ⚠️ | 3-H発表はクレム・レヌーフ（1978-79年度会長）。1977-78年度会長との混同に注意。 |
| 「RIの職員は8,000人」 | ✕ | 公式は本部＋国際事務所で800人超。求人サイトの集計値は誤り。 |
| 「Charity Navigator 4つ星○年連続」 | 年数要確認 | 15年／17年の両方の記述あり。 |

## D. 卓話の「つかみ」候補（3つ）

1. **「胸のバッジの真ん中の切り欠き、何のためか答えられますか」**（→キー溝の話）
2. **「東京クラブの番号は855番。では、なぜ1949年に同じ番号で戻れたのか」**（→復帰の3条件）
3. **「2024-25年の『ロータリーのマジック』が、最後の『テーマ』だと知っていましたか」**（→メッセージ制への移行）
